# Bank Management System (Java)

A console-based Bank Management System developed using Java.

## Features
- Admin login
- User account creation & login
- Deposit & withdrawal
- Money transfer between accounts
- Password management
- File-based data storage

## Technologies Used
- Java
- File Handling
- OOP Concepts

## How to Run
1. Compile the program:
   javac Bank.java
2. Run the program:
   java Bank
